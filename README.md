# D288 Task 1 — Back-End Application Programming

This project implements the Spring back end requested in the D288 Task 1 assessment.

Implemented:
- Spring Data JPA
- Spring Data REST
- MySQL Driver
- Lombok
- controllers, entities, dao, services, and config packages
- UML-aligned JPA entities and StatusType enum
- repository interfaces with CORS support
- purchase/purchase-response DTOs
- checkout service and implementation
- checkout REST controller
- five sample customers, guarded so they are not recreated after five exist

## Before running in the WGU lab
1. Open the project in IntelliJ IDEA Ultimate.
2. Copy the lab-supplied `application.properties` values into `src/main/resources/application.properties`.
3. Confirm the lab MySQL database is running.
4. Keep the supplied Angular front end unchanged.
5. Run `D288Application`.
6. Complete the checkout test and collect the screenshots required by the assessment.
